# Generic profile

The included profile is fictional and safe to replace. It is a schema example, not a design recommendation or approved brand.

An implementation profile must define:

- organization identity and terminology;
- approved brand and templates;
- accessibility target and required evidence;
- information classifications and repository boundaries;
- reviewer and authorizer roles;
- publishing channels, taxonomy, support, and maintenance rules;
- approved tools and adapters.

Keep real organization profiles in a private repository and pin the TEOS core version they implement.
