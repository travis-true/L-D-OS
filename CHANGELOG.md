# Changelog

## 0.2.0 — 2026-08-30

- Added a public, responsive, WCAG 2.2 AA-targeted guided intake as the GitHub Pages homepage.
- Added JSON-configured questions and conditional branching for seven request types.
- Added browser-only Save, Resume, and Clear controls plus draft JSON and Markdown downloads.
- Added complete intake, build-brief, non-authoritative routing, and prefilled GitHub Issue outputs.
- Added public-data acknowledgment, source-reference-only controls, and long-Issue clipboard fallback.
- Added accessible web views of the operating model, workflows, lanes, gates, schemas, and pilot approach.
- Added deterministic JavaScript tests, site validation, sample intake outputs, and Pages deployment automation.
- Resolved the public license decision: MIT for code and CC BY 4.0 for documentation and L&D OS content.
- Preserved the v0.1.0 governed core paths and IDs.

## 0.1.0 — 2026-08-30

- Converted the approved Phase 0–10 L&D lifecycle into seven executable workflows.
- Added fast-track, standard, and controlled operating lanes.
- Added machine-readable decision gates and JSON Schemas.
- Integrated a six-step production surface, five-dimension format routing, format-specific definition-of-done checks, a variable-driven organization profile, and stage-based assistant contracts.
- Added source-authority, evidence, QA, release, maintenance, and change-control records.
- Added GitHub issue, pull-request, ownership, and validation scaffolding.
- Deferred the supplied rendering engine to an experimental adapter contract pending hardening and accessibility validation.
