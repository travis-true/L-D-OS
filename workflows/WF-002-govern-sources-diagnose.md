# WF-002 — Govern sources and diagnose

Trigger: authorized request and lane.  
Outcome: approved source set and evidence-based solution recommendation.  
Accountable role: performance consultant or assigned analyst.

| Step | Actor | Action | Output/evidence |
| --- | --- | --- | --- |
| 2.1 | Analyst | Register every applicable source with owner, version, scope, authority, classification, and limitations. | source records |
| 2.2 | Source reviewer | Resolve authority by mandate, ownership, approval, currency, scope, specificity, evidence, integrity, and permitted use. | source disposition |
| 2.3 | Analyst | Preserve conflicts, gaps, assumptions, and unsupported claims. | issue/evidence records |
| 2.4 | Source authorizer | Approve, condition, or reject the governed source set. | G01 decision |
| 2.5 | Analyst | Define desired performance, current performance, audience context, causes, barriers, and consequences. | diagnosis record |
| 2.6 | Analyst | Test learning causes and non-learning causes; do not assume training is the solution. | training-fit finding |
| 2.7 | Analyst | Recommend training, performance support, communication, process/system change, manager action, blended intervention, further discovery, or no action. | recommendation |
| 2.8 | Authorizer | Approve the recommendation or return it for evidence. | G03 decision |

Required gates: `G01`, `G03`.

Stop when a governing conflict or evidence gap could materially change the recommendation.
